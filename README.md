# Weekly Diet

A simple web app for planning and tracking my weekly diet.
Deployed using GitHub pages.

## Structure
- `index.html` – main page markup
- `styles.css` – styling for the page
- `script.js` – interactive behavior

## Getting Started
1. Open `index.html` in your browser (double‑click it or use a local server).
2. Edit `styles.css` and `script.js` to customize the look and behavior.
3. Edit `index.html` weekly in order to keep the menu updated.
